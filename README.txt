# ТХ ТМ Telegram Bot

## Что есть в первой версии
- Регистрация Roblox-ника с одобрением/отклонением/игнорированием заявки.
- Профиль, позиции, поиск клубов, карьерный статус, Топ СНГ.
- Объявления с модерацией.
- Команды `/getowner`, `/removeowner`, `/ban`, `/unban`, `/getadmin`, `/removeadmin`, `/settop`, `/createclub`, `/setgroup`.

## Установка
1. Загрузите файлы из архива в корень репозитория, заменив `package.json` и `src/commands.js`, добавив `src/database.js`.
2. Оставьте существующий `index.js` — он уже подключает `registerCommands(bot)`.
3. В настройках хостинга задайте переменные окружения:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather.
   - `OWNER_IDS` — ваш Telegram ID (можно несколько через запятую).
   - `DATA_DIR` — постоянная папка для данных, например `./data`.
4. Установите зависимости (`npm install`) и запустите (`npm start`).
5. Добавьте бота в группу «Админы Тх Тм» и сделайте администратором. В группе выполните `/setgroup`.
6. В личном чате бота выполните `/start`.

## Важно
- Не публикуйте токен бота в GitHub. Храните его только в переменных окружения хостинга.
- `OWNER_IDS` должен содержать ваш Telegram ID, иначе никто не сможет выдавать/снимать админские права.
- Для SQLite хостинг должен сохранять папку `DATA_DIR` между перезапусками и деплоями. Если хостинг не поддерживает постоянный диск, база может потеряться.
- Игнорирование оставляет заявку в статусе `pending`, кнопки остаются доступны.
- Эта версия — базовая: полноценное назначение клуба конкретному игроку, набор в клуб и расширенные права клуба можно добавить следующим этапом.
